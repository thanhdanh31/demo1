
# PHASE 5 – TESTING

## 1. Mục tiêu
Kiểm thử hệ thống đối soát hoa hồng TikTok Affiliate tại Phúc Long Mart.

## 2. Phạm vi kiểm thử
- Kiểm thử dữ liệu SKU.
- Kiểm thử trạng thái đơn hàng.
- Kiểm thử hàng hoàn/trả.
- Kiểm thử quyết toán hoa hồng.
- Kiểm thử các chỉ số KPI.

## 3. Tài liệu kiểm thử
- Test cases: Danh sách trường hợp kiểm thử.
- Test data: Dữ liệu mẫu.
- KPI: Các chỉ số cần đối chiếu.
- Bug log: Danh sách lỗi phát hiện.

## 4. Kết quả
Kết quả từng trường hợp được ghi nhận là PASS hoặc FAIL sau khi thực hiện kiểm thử.
